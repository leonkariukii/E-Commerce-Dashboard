# 🚗 AutoSpares Shop

A modern, responsive **auto-spares product showcase** designed for an online automotive parts store. The project focuses on CSS layout, responsive design, interactive product cards, accessibility, dark mode, and conversion-focused user interface design.

---

## 📌 Project Overview

**AutoSpares Shop** is a frontend product showcase for an online automotive spare-parts store.

The project demonstrates practical understanding of:

- HTML5 semantic structure
- CSS3 styling
- CSS Grid
- Flexbox
- Responsive web design
- Product card design
- Hover effects and transitions
- Product detail modals
- Shopping cart UI
- Filter and sort interfaces
- CSS custom properties
- Dark mode
- Accessibility
- Performance optimization

The goal is to create a shopping experience that is **simple, professional, responsive, and easy to navigate** across desktop, tablet, and mobile devices.

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Create a professional auto-spares product showcase.
2. Build a responsive product grid using CSS Grid.
3. Design reusable product cards.
4. Implement interactive UI elements.
5. Create a product-detail modal.
6. Design a static shopping-cart sidebar.
7. Create filtering and sorting interfaces.
8. Develop a consistent automotive brand identity.
9. Implement responsive and accessible design.
10. Optimize the interface for different browsers and devices.

# ✨ Key Features

## 1. Product Grid

Products are displayed using a responsive **CSS Grid** layout.

Each product card contains:

- Product image
- Product title
- Product description
- Price
- Rating
- Add-to-cart button
- Product details interaction

The grid automatically adapts to different screen sizes.
